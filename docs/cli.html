Command Line Reference

The TaraDSP executable is a command-line audio processing tool. It applies FFT convolution with impulse responses, resamples audio, and applies mastering dithering and fades.

Quick start

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Options

OptionLong formValueDescription
-x --in1 <file> Input WAV file (the audio signal to process)
-y --in2 <file> Impulse response WAV file (optional — if omitted, a unit impulse is used, producing a pass-through with mastering)
-o --output <file> Output WAV file
-b --bits 16|24|32 Output bit depth (default: 24)
-r --rate <Hz> Target sample rate (e.g. 44100, 48000, 96000). If set, both input and IR are resampled to this rate.
-l --length <samples> Truncate output to this many samples (0 = no truncation)
-t --trim <dB> Trim silence below this threshold (e.g. -60). Applied to the IR before convolution.
-f --fade <ms> Apply fade-out of this duration in milliseconds to the IR. A 1ms fade-in is always applied.
-m --mono (flag) Force mono output (downmix to single channel)
--min (flag) Convert the convolved output to minimum phase
-h --help (flag) Show help and usage information

Examples

Basic convolution

Convolve a guitar signal with a cabinet impulse response:

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Mastering with dithering

Apply mastering to a mix without convolution (no IR), output 16-bit with dithering:

TaraDSP -x mix.wav -o master.wav -b 16

Resampling

Convert a 44.1kHz file to 48kHz with convolution:

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Minimum phase conversion

Convert a linear-phase IR to minimum phase for lower latency:

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Trim silence and apply fade

Trim silence below -60dB from the IR, apply a 50ms fade-out:

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Mono output

Downmix stereo to mono:

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Truncate for modelers

Truncate to 1024 samples (for guitar modelers like GP-200):

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

Input Formats

WAV (PCM)8, 16, 24, 32-bitMono, Stereo, MultichannelAll standard WAV formats supported
WAV (IEEE Float)32-bit floatMono, StereoFull dynamic range, no clipping

Output Formats

Bit DepthFormatDitheringNotes
16-bitWAV (PCM)TPDF with error feedbackCD quality, universally compatible
24-bitWAV (PCM)None (native resolution)Studio quality, recommended
32-bitWAV (IEEE Float)NoneMaximum dynamic range, for further processing
Tip: For the best results, use 24-bit output. It provides more headroom than 16-bit and is smaller than 32-bit float. The mastering dither is only applied for 16-bit output.

Configuration File

TaraDSP reads a settings.ini file from the same directory as the executable (or the current working directory). This file can set default values for artist metadata, bit depth, dither amount, and more.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
