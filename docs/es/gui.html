Interfaz Gráfica de Usuario

La GUI de TaraDSP proporciona el mismo procesamiento de audio profesional que la CLI en una ventana fácil de usar. Es la forma recomendada de procesar archivos interactivamente.

Controles

ControlTipoDescripción
Archivo de Origen Selector de archivo El archivo WAV de entrada a procesar. Haz clic para buscar un archivo.
Respuesta al Impulso Selector de archivo El archivo WAV de IR con el que convolucionar. Déjalo vacío para el modo passthrough (solo masterización: dither, normalizar, fundidos).
Archivo de Salida Texto + explorar La ruta del archivo WAV de salida. Haz clic en "..." para buscar una ubicación.
Profundidad de Bits Combo: 16 / 24 / 32 Profundidad de bits de salida. Se recomienda 24 para calidad de estudio. 16 aplica dithering TPDF. 32 genera IEEE float.
Frecuencia de Muestreo Combo Frecuencia de muestreo objetivo: 0 (mantener original), 44100, 48000, 88200, 96000, 176400, 192000. Tanto la entrada como la IR se remuestrean si es necesario.
Longitud de Truncamiento Spin edit Muestras máximas de salida. 0 = sin límite. Útil para modeladores de guitarra (p. ej. 1024 para GP-200). Se aplica un fundido de salida corto en el punto de truncamiento para prevenir clics.
Fundido de Salida Spin edit (ms) Duración del fundido de salida aplicado a la IR antes de la convolución. Siempre se aplica un fundido de entrada de 1ms para prevenir clics al inicio.
Recortar Silencio Spin edit (dB) Umbral por debajo del cual las muestras se consideran silencio y se eliminan de la IR. Establece 0 para desactivar. Típico: -60 a -80.
Salida Mono Casilla Mezcla la salida a un solo canal.
Fase Mínima Casilla Convierte la salida convolucionada a fase mínima. Elimina el pre-ringing y reduce la latencia.
PROCESS Botón Ejecuta el pipeline de procesamiento. El progreso se muestra en el registro.
Registro Memo de solo lectura Muestra el progreso por paso: cargando, remuestreando, convolucionando, normalizando, guardando. Los errores se muestran en texto rojo.

Pipeline de Procesamiento

Cuando haces clic en PROCESS, la GUI ejecuta los siguientes pasos en orden:

  1. Cargar entrada — Leer el archivo WAV de origen (PCM o float de 8/16/24/32-bit)
  2. Cargar IR — Leer la respuesta al impulso (si se especifica)
  3. Recortar silencio — Eliminar el silencio por debajo del umbral de la IR (si se establece)
  4. Aplicar fundido — Aplicar fundido de salida a la IR (si se establece)
  5. Remuestrear — Remuestrear la entrada y la IR a la frecuencia objetivo (si se establece)
  6. Convolucionar — Convolución FFT por canal
  7. Fase mínima — Convertir a fase mínima (si está marcado)
  8. Normalizar — Normalizar el pico a 1.0
  9. Truncar — Truncar a la longitud máxima (si se establece)
  10. Guardar — Escribir el WAV de salida con dithering (16-bit) o float (32-bit)

Consejos

Consejo 1: Deja el campo de IR vacío para usar la GUI como una herramienta de masterización — aplicará dither, normalizará y aplicará fundidos sin convolución.
Consejo 2: Para simulación de cabinet de guitarra, establece la longitud de truncamiento en 1024 o 2048 muestras y habilita la fase mínima para el sonido más ajustado y de menor latencia.
Consejo 3: Usa salida de 24 bits para el mejor equilibrio entre calidad y tamaño de archivo. 16 bits solo se necesita para compatibilidad con CD.
Consejo 4: La GUI lee settings.ini del mismo directorio que el ejecutable para los valores por defecto (nombre del artista, profundidad de bits, cantidad de dither, longitud de truncamiento).

Archivo de Configuración

La GUI lee un archivo settings.ini para los valores por defecto:

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
