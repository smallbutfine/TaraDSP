¿Qué es TaraDSP?

TaraDSP es una herramienta profesional de procesamiento de audio que aplica convolución basada en FFT con respuestas al impulso, remuestrea audio, y aplica dithering y fundidos de calidad de masterización. Está diseñada para músicos, ingenieros de audio y desarrolladores que necesitan resultados de calidad de estudio de una herramienta de línea de comandos ligera y multiplataforma.

Convolución FFT

Convolución de alta velocidad usando la librería PFFFT (Pretty Fast FFT). Convoluciona cualquier señal de audio con respuestas al impulso de cabinet, IRs de reverberación o filtros personalizados en segundos.

Multiplataforma

Binarios nativos para Windows (x86_64), macOS (Intel + Apple Silicon), y Linux (x86_64 + ARM). Una herramienta, cada plataforma.

Dither de Masterización

Dithering TPDF (Función de Densidad de Probabilidad Triangular) con retroalimentación de error para salida transparente de 16 y 24 bits.

Remuestreo

Conversión de frecuencia de muestreo de alta calidad mediante SoX Resampler (libsoxr) con alternativa de interpolación lineal. Convierte entre cualquier frecuencia.

Fase Mínima

Convierte respuestas al impulso de fase lineal a fase mínima para menor latencia y un sonido más natural.

Build Multiplataforma

CI/CD automatizado con GitHub Actions. La cadena de herramientas basada en fpcupdeluxe instala FPC, Lazarus y todos los compiladores cruzados automáticamente.

Inicio Rápido

Aplica una respuesta al impulso a un archivo de audio:

TaraDSP -x input.wav -y impulse_response.wav -o output.wav

Convierte a 24 bits con remuestreo:

TaraDSP -x input.wav -y ir.wav -o output.wav -b 24 -r 48000

Aplica fundidos y recorta el silencio:

TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60
