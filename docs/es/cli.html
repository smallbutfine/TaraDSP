Referencia de Línea de Comandos

El ejecutable TaraDSP es una herramienta de procesamiento de audio de línea de comandos. Aplica convolución FFT con respuestas al impulso, remuestrea audio, y aplica dithering y fundidos de masterización.

Inicio rápido

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Opciones

OpciónForma largaValorDescripción
-x --in1 <archivo> Archivo WAV de entrada (la señal de audio a procesar)
-y --in2 <archivo> Archivo WAV de respuesta al impulso (opcional — si se omite, se usa un impulso unitario, produciendo una pasada con masterización)
-o --output <archivo> Archivo WAV de salida
-b --bits 16|24|32 Profundidad de bits de salida (por defecto: 24)
-r --rate <Hz> Frecuencia de muestreo objetivo (p. ej. 44100, 48000, 96000). Si se establece, tanto la entrada como la IR se remuestrean a esta frecuencia.
-l --length <muestras> Truncar la salida a esta cantidad de muestras (0 = sin truncamiento)
-t --trim <dB> Recortar el silencio por debajo de este umbral (p. ej. -60). Se aplica a la IR antes de la convolución.
-f --fade <ms> Aplicar un fundido de salida de esta duración en milisegundos a la IR. Siempre se aplica un fundido de entrada de 1ms.
-m --mono (bandera) Forzar salida mono (mezcla a un solo canal)
--min (bandera) Convertir la salida convolucionada a fase mínima
-h --help (bandera) Mostrar ayuda e información de uso

Ejemplos

Convolución básica

Convolucionar una señal de guitarra con una respuesta al impulso de cabinet:

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Masterización con dithering

Aplicar masterización a una mezcla sin convolución (sin IR), salida de 16 bits con dithering:

TaraDSP -x mix.wav -o master.wav -b 16

Remuestreo

Convertir un archivo de 44.1kHz a 48kHz con convolución:

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Conversión a fase mínima

Convertir una IR de fase lineal a fase mínima para menor latencia:

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Recortar silencio y aplicar fundido

Recortar el silencio por debajo de -60dB de la IR, aplicar un fundido de salida de 50ms:

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Salida mono

Mezclar estéreo a mono:

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Truncar para modeladores

Truncar a 1024 muestras (para modeladores de guitarra como GP-200):

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

WAV (IEEE Float)32-bit floatMono, EstéreoRango dinámico completo, sin recorte

Formatos de Salida

Profundidad de BitsFormatoDitheringNotas
16-bitWAV (PCM)TPDF con retroalimentación de errorCalidad CD, universalmente compatible
24-bitWAV (PCM)Ninguno (resolución nativa)Calidad de estudio, recomendado
32-bitWAV (IEEE Float)NingunoMáximo rango dinámico, para procesamiento adicional
Consejo: Para obtener los mejores resultados, usa salida de 24 bits. Proporciona más margen que 16 bits y es más pequeño que 32-bit float. El dither de masterización solo se aplica para salida de 16 bits.

Archivo de Configuración

TaraDSP lee un archivo settings.ini del mismo directorio que el ejecutable (o del directorio de trabajo actual). Este archivo puede establecer valores por defecto para metadatos de artista, profundidad de bits, cantidad de dither y más.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
