Загрузки

Готовые бинарники прикреплены к каждому релизу GitHub:

ПлатформаАртефактПримечания
Windows 64-бит TaraDSP_<version>_Setup.exe Установщик Inno Setup. Включает GUI, CLI, libpffft.dll и конфигурацию.
macOS Intel TaraDSP_gui<version>-macos-intel.zip Универсальный bundle приложения. Распакуйте и перетащите в /Applications.
macOS Apple Silicon TaraDSP_gui<version>-macos-aarch64.zip Универсальный bundle приложения. Распакуйте и перетащите в /Applications.
Linux x86_64 TaraDSP<version>-linux-x64.tar.gz Распакуйте и запустите. Включает libpffft.so.
Linux ARM TaraDSP<version>-linux-arm.tar.gz Распакуйте и запустите. Включает libpffft.so.
macOS: Приложение не подписано. При первом запуске используйте правый клик → Открыть (или xattr -dr com.apple.quarantine в Терминале).
Linux: Архив включает разделяемую библиотеку libpffft.so. Убедитесь, что она лежит рядом с исполняемым файлом TaraDSP, или задайте LD_LIBRARY_PATH соответствующим образом.

Сборка из Исходного Кода

См. Документацию для инструкций по сборке. Кратко:

./build_all.bat            # все 5 целей + пакеты в Deploy/
./build_all.bat --check    # проверить только цепочку инструментов
