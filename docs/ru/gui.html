Графический Интерфейс Пользователя

GUI TaraDSP предоставляет ту же профессиональную обработку аудио, что и CLI, в простом в использовании окне. Это рекомендуемый способ интерактивной обработки файлов.

Элементы управления

ЭлементТипОписание
Исходный файл Выбор файла Входной WAV-файл для обработки. Нажмите, чтобы выбрать файл.
Импульсная характеристика Выбор файла WAV-файл IR, с которым свернуть. Оставьте пустым для сквозного режима (только мастеринг: дизеринг, нормализация, фейды).
Выходной файл Текст + обзор Путь к выходному WAV-файлу. Нажмите «...», чтобы выбрать местоположение.
Разрядность Список: 16 / 24 / 32 Разрядность вывода. 24 рекомендуется для студийного качества. 16 применяет дизеринг TPDF. 32 выдаёт IEEE float.
Частота дискретизации Список Целевая частота дискретизации: 0 (оставить исходную), 44100, 48000, 88200, 96000, 176400, 192000. И вход, и IR ресемплируются при необходимости.
Длина обрезки Спин-поле Максимум выходных сэмплов. 0 = без лимита. Полезно для гитарных модельеров (например, 1024 для GP-200). Короткий фейд-аут применяется в точке обрезки для предотвращения щелчков.
Фейд-аут Спин-поле (мс) Длительность фейд-аута, применяемого к IR перед свёрткой. Фейд-ин 1 мс всегда применяется для предотвращения щелчков в начале.
Обрезка тишины Спин-поле (дБ) Порог, ниже которого сэмплы считаются тишиной и удаляются из IR. Установите 0 для отключения. Типично: -60 до -80.
Моно-вывод Флажок Свести вывод в один канал.
Минимальная фаза Флажок Преобразовать свёрнутый вывод в минимальную фазу. Убирает pre-ringing и снижает задержку.
PROCESS Кнопка Запустить конвейер обработки. Прогресс показывается в журнале.
Журнал Поле только для чтения Показывает прогресс по шагам: загрузка, ресемплинг, свёртка, нормализация, сохранение. Ошибки показываются красным текстом.

Конвейер обработки

Когда вы нажимаете PROCESS, GUI выполняет следующие шаги по порядку:

  1. Загрузить вход — Прочитать исходный WAV-файл (PCM или float 8/16/24/32 бита)
  2. Загрузить IR — Прочитать импульсную характеристику (если указана)
  3. Обрезать тишину — Удалить тишину ниже порога из IR (если задано)
  4. Применить фейд — Применить фейд-аут к IR (если задано)
  5. Ресемплинг — Ресемплировать вход и IR на целевую частоту (если задана)
  6. Свёртка — БПФ-конволюция по каналам
  7. Минимальная фаза — Преобразовать в минимальную фазу (если отмечено)
  8. Нормализация — Нормализовать пик до 1.0
  9. Обрезка — Обрезать до максимальной длины (если задано)
  10. Сохранить — Записать выходной WAV с дизерингом (16 бит) или float (32 бита)

Советы

Совет 1: Оставьте поле IR пустым, чтобы использовать GUI как инструмент мастеринга — он применит дизеринг, нормализует и применит фейды без свёртки.
Совет 2: Для симуляции гитарного кабинета установите длину обрезки 1024 или 2048 сэмплов и включите минимальную фазу для самого плотного звука с наименьшей задержкой.
Совет 3: Используйте вывод 24 бита для лучшего баланса качества и размера файла. 16 бит нужен только для совместимости с CD.
Совет 4: GUI читает settings.ini из того же каталога, что и исполняемый файл, для значений по умолчанию (имя исполнителя, разрядность, величина дизеринга, длина обрезки).

Файл конфигурации

GUI читает файл settings.ini для значений по умолчанию:

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
