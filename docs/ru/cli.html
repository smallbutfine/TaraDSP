Справочник по командной строке

Исполняемый файл TaraDSP — это инструмент обработки аудио из командной строки. Он применяет БПФ-конволюцию с импульсными характеристиками, выполняет ресемплинг аудио и применяет мастеринг-дизеринг и фейды.

Быстрый старт

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Опции

ОпцияПолная формаЗначениеОписание
-x --in1 <файл> Входной WAV-файл (аудиосигнал для обработки)
-y --in2 <файл> WAV-файл импульсной характеристики (необязательно — если опущен, используется единичный импульс, дающий сквозной проход с мастерингом)
-o --output <файл> Выходной WAV-файл
-b --bits 16|24|32 Разрядность вывода (по умолчанию: 24)
-r --rate <Гц> Целевая частота дискретизации (например, 44100, 48000, 96000). Если задана, и вход, и IR ресемплируются на эту частоту.
-l --length <сэмплы> Обрезать вывод до этого количества сэмплов (0 = без обрезки)
-t --trim <дБ> Обрезать тишину ниже этого порога (например, -60). Применяется к IR перед конволюцией.
-f --fade <мс> Применить фейд-аут этой длительности в миллисекундах к IR. Фейд-ин 1 мс применяется всегда.
-m --mono (флаг) Принудительный моно-вывод (сведение в один канал)
--min (флаг) Преобразовать свёрнутый вывод в минимальную фазу
-h --help (флаг) Показать справку и информацию об использовании

Примеры

Базовая конволюция

Свернуть сигнал гитары с импульсной характеристикой кабинета:

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Мастеринг с дизерингом

Применить мастеринг к миксу без конволюции (без IR), вывод 16 бит с дизерингом:

TaraDSP -x mix.wav -o master.wav -b 16

Ресемплинг

Преобразовать файл 44.1 кГц в 48 кГц с конволюцией:

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Преобразование в минимальную фазу

Преобразовать IR с линейной фазой в минимальную фазу для меньшей задержки:

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Обрезка тишины и применение фейда

Обрезать тишину ниже -60 дБ из IR, применить фейд-аут 50 мс:

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Моно-вывод

Свести стерео в моно:

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Обрезка для модельеров

Обрезать до 1024 сэмплов (для гитарных модельеров типа GP-200):

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

ФорматРазрядностьКаналыПримечания

Форматы выхода

РазрядностьФорматДизерингПримечания
16 битWAV (PCM)TPDF с обратной связью по ошибкеКачество CD, универсальная совместимость

Совет: Для лучших результатов используйте вывод 24 бита. Он даёт больше запаса, чем 16 бит, и меньше, чем 32-битный float. Мастеринг-дизеринг применяется только для вывода 16 бит.

Файл конфигурации

TaraDSP читает файл settings.ini из того же каталога, что и исполняемый файл (или из текущего рабочего каталога). Этот файл может задавать значения по умолчанию для метаданных исполнителя, разрядности, величины дизеринга и многого другого.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
