1. БПФ-конволюция

TaraDSP использует библиотеку PFFFT (Pretty Fast FFT) для высокоскоростной свёртки. Процесс работает следующим образом:

  1. Входной сигнал и импульсная характеристика дополняются нулями до следующей степени 2 (минимум 32 сэмпла для выравнивания PFFFT).
  2. Оба сигнала преобразуются в частотную область с помощью прямого БПФ (pffft_transform с PFFFT_FORWARD).
  3. Сигналы в частотной области перемножаются (теорема о свёртке) через pffft_zconvolve_accumulate.
  4. Результат преобразуется обратно во временную область с помощью обратного БПФ (pffft_transform с PFFFT_BACKWARD).
  5. Вывод масштабируется на 1/N и нормализуется до пика 1.0.
Почему PFFFT? PFFFT специально разработана для аудиоприложений. Она поддерживает вещественное БПФ (не только комплексное), которое вдвое быстрее для вещественных аудиосигналов. Она также обрабатывает инструкции SIMD (SSE, NEON) для дополнительной скорости.
Важно: нужно использовать pffft_transform (внутренний формат), а НЕ pffft_transform_ordered (формат отображения). Функция zconvolve_accumulate ожидает внутренний формат. Использование неправильной функции даёт неверные результаты свёртки.

2. Ресемплинг

TaraDSP может ресемплировать аудио на другую частоту дискретизации. Выбор движка ресемплинга следует этой приоритетности:

  1. SoX Resampler (libsoxr) — высочайшее качество, используется, когда доступен
  2. R8Brain — высокое качество, используется, когда доступен
  3. FinalCD — внешний инструмент, используется, когда доступен
  4. Линейная интерполяция — запасной вариант, всегда доступен

При запросе ресемплинга (опция -r в CLI или селектор частоты дискретизации в GUI) и входной сигнал, и импульсная характеристика ресемплируются на целевую частоту перед свёрткой.

3. Мастеринг-Дизеринг

При выводе 16-битного аудио TaraDSP применяет дизеринг TPDF (Треугольная Функция Плотности Вероятности) с обратной связью по ошибке. Этот процесс:

  1. Добавляет небольшое количество случайного шума (2 LSB размах) к сигналу.
  2. Квантует до 16 бит.
  3. Вычисляет ошибку квантования.
  4. Подаёт ошибку обратно в следующий сэмпл (обратная связь по ошибке).
Зачем дизеринг? Без дизеринга квантование до 16 бит даёт гармонические искажения на низких уровнях. Дизеринг TPDF преобразует эти искажения в постоянный низкоуровневый шумовой пол, который гораздо менее слышен и звучит более естественно.

4. Преобразование в Минимальную Фазу

Импульсные характеристики с линейной фазой имеют симметричный pre-ringing, который может звучать неестественно. Опция --min (CLI) или флажок «Минимальная фаза» (GUI) преобразует свёрнутый вывод в минимальную фазу, которая имеет:

  • Нет pre-ringing (энергия только после основного импульса)
  • Меньшая задержка
  • Более естественный звук для симуляции кабинета и реверберации

Алгоритм преобразования:

  1. Вычислить БПФ сигнала.
  2. Извлечь спектр magnitude.
  3. Вычислить логарифм magnitude.
  4. Вычислить реальный цепстр (обратное БПФ логарифма magnitude).
  5. Сложить цепстр, чтобы создать минимальную фазу.
  6. Вычислить комплексный спектр (magnitude × минимальная фаза).
  7. Обратное БПФ для получения сигнала минимальной фазы.

5. Фейды и Обрезка

TaraDSP может применять фейды и обрезать тишину из импульсной характеристики перед свёрткой:

  • Обрезка (-t / спин в GUI): Удаляет сэмплы ниже порога (в дБ) с начала и конца IR. Полезно для очистки импульсных характеристик с заполнением тишиной.
  • Фейд (-f / спин в GUI): Применяет фейд-аут указанной длительности (в мс) к концу IR. Фейд-ин 1 мс всегда применяется для предотвращения щелчков. Полезно для сглаживания концов IR.

8. Сборка из Исходного Кода

Предварительные требования

  • FreePascal Compiler (FPC) 3.2.2+ или Lazarus IDE 3.0+
  • Lazarus/LCL для GUI
  • Для полной мультиплатформенной сборки: кросс-компиляторы FPC (ppcrossx64, ppcrossa64, ppcrossarm) и Inno Setup 6
  • Python 3 (для tools/zip_app.py)
  • Zig (автоматически загружается build_all.bat для кросс-компиляции C под Linux)

Собрать всё

./build_all.bat            # все 5 целей + пакеты в Deploy/
./build_all.bat --check    # проверить только цепочку инструментов

Собрать одну программу

# CLI
fpc -O2 -Fusrc -Sg -Sc TaraDSP.lpr

# GUI
lazbuild --build-all gui/TaraDSP_gui.lpi
