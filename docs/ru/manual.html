1. Что такое TaraDSP?

TaraDSP — это профессиональный инструмент обработки аудио, который делает одну вещь исключительно хорошо: БПФ-конволюцию. Если вы когда-либо использовали симулятор гитарного кабинета, конволюционную реверберацию или цепочку мастеринга с аналогово-моделированным EQ, вы использовали конволюцию.

TaraDSP даёт вам эту мощь в лёгком, кроссплатформенном пакете. Windows, macOS, Linux. CLI для пакетной обработки, GUI для интерактивной работы.

2. Наука о Конволюции

Конволюция применяет sonic-характеристики одного сигнала (импульсной характеристики) к другому (вашему аудио). Когда вы играете сухую гитару через кабинет, кабинет окрашивает звук — резонансы, АЧХ, затухание. Конволюция математически применяет эту окраску.

Почему БПФ? Прямая конволюция — это O(n²) — миллиарды операций для секундного файла. БПФ сокращает это до O(n log n) через теорему о свёртке:

Свёртка во времени = Умножение в частоте
  1. БПФ обоих сигналов → частотная область
  2. Перемножить их → одно умножение на бин
  3. Обратное БПФ → обратно во временную область

Ускорение в 5000×. PFFFT дополнительно ускоряет с помощью SIMD (SSE/NEON) — 4-8 сэмплов за инструкцию.

4. Цепочка Обработки

Когда вы запускаете TaraDSP, аудио проходит через эту цепочку. Каждый шаг необязателен.

ШагЧтоФлаг CLI
1Загрузить вход (WAV 8/16/24/32 бита → float)-x
2Загрузить IR (необязательно — сквозной проход, если пусто)-y
3Обрезать тишину из IR-t <дБ>
4Применить фейды (вход 1мс всегда, выход необязателен)-f <мс>
5Ресемплинг (SoX → R8Brain → FinalCD → линейный)-r <Гц>
6БПФ-свёртка (PFFFT)(автоматически)
7Минимальная фаза (убрать pre-ringing)--min
8Нормализация (пик → 0 dBFS)(автоматически)
9Длина обрезки-l <сэмплы>
10Дизеринг + Сохранение-b <16|24|32>

5. Мастеринг-Дизеринг

Проблема: Квантование из 24 бит в 16 бит без дизеринга создаёт гармонические искажения на низких уровнях.

Решение: TPDF — добавляет 2 LSB треугольного шума перед квантованием. Преобразует искажения в постоянный шумовой пол — менее слышно, более естественно.

Реализация TaraDSP:

  • Шум TPDF: Два случайных значения, суммированные (треугольное распределение)
  • Обратная связь по ошибке: Ошибка квантования подаётся обратно, формируя спектр шума
  • Масштабирование, зависящее от сигнала: 70% дизеринга на очень низких уровнях (< -90 dBFS)
Когда использовать: Всегда делайте дизеринг для 16 бит. Никогда не делайте дизеринг для 24/32 бит. Делайте дизеринг один раз, только на финальной стадии вывода.

6. Минимальная Фаза

Pre-ringing: IR с линейной фазой имеют симметричную энергию — до И после основного импульса. Энергия до — это pre-ringing, который звучит неестественно (в природе звук приходит после, никогда до).

Что делает минимальная фаза: Преобразует IR с линейной фазой в минимальную фазу:

  • Нет pre-ringing
  • Меньшая задержка
  • Та же АЧХ (magnitude неизменна)

Алгоритм: Метод реального цепстра — БПФ → лог magnitude → обратное БПФ (цепстр) → сложение → БПФ → комплексный спектр → обратное БПФ.

Когда использовать: Всегда для симуляции кабинета. Всегда для реального времени. Необязательно для реверберации (некоторые предпочитают просторность линейной фазы).

7. Ресемплинг

Зачем: Несовпадающие частоты (IR 44.1k, проект 48k), целевое устройство ожидает определённую частоту, релиз на CD (44.1k).

Алиасинг: Понижение дискретизации без фильтрации заставляет частоты выше Найквиста складываться как металлические артефакты.

Приоритет движка:

  1. SoX Resampler (libsoxr) — VHQ, правильный антиалиасинг. Лучший вариант.
  2. R8Brain — VHQ, используется, когда libsoxr недоступен.
  3. FinalCD — внешний инструмент.
  4. Линейная интерполяция — запасной вариант, без антиалиасинга.

Установите libsoxr для лучших результатов. Поставляется как libsoxr.dll / .dylib / .so.0.

8. Фейды и Обрезка

Обрезка тишины: IR часто имеют тишину в начале/конце. Обрезка её удаляет:

  • -60 — типично для IR
  • -80 — агрессивно
  • 0 — отключено

Фейды:

  • Фейд-ин: Всегда 1мс (автоматически) — предотвращает щелчки в начале
  • Фейд-аут: Задаётся пользователем (-f <мс>) — предотвращает щелчки в конце

Линейная рампа усиления: 1.0 → 0.0 (фейд-аут) или 0.0 → 1.0 (фейд-ин).

9. Практические Рабочие Процессы

Симуляция Гитарного Кабинета

TaraDSP -x guitar_di.wav -y cab_57.wav -o guitar_amped.wav --min -l 2048 -b 24

Конволюционная Реверберация

TaraDSP -x vocal_dry.wav -y concert_hall.wav -o vocal_reverb.wav -f 100 -b 24

Мастеринг с Дизерингом

TaraDSP -x mix_24bit.wav -o master_16bit.wav -b 16

Преобразование Частоты Дискретизации

TaraDSP -x recording_96k.wav -o master_44k1.wav -r 44100 -b 16

Пакетная Обработка

for %f in (*.wav) do TaraDSP -x "%f" -y cab_ir.wav -o "processed_%f" --min -b 24

10. Комбинирование Двух IR

TaraDSP может слить две импульсные характеристики в одну новую IR. Это полезно для:

  • Смесь Каб + Микрофон: Скомбинируйте IR, микрофонированную вблизи, с IR, микрофонированной в комнате, чтобы создать кастомную смесь
  • Каб + EQ: Сверните IR каба с IR кривой EQ, чтобы запечь EQ в каб
  • Два каба смешаны: Смешайте два разных динамика (например, 4x12 + 2x12) в одну IR
  • IR + Реверберация: Скомбинируйте IR каба с короткой IR комнаты для звука «кабинет в комнате»

Как это работает: Конволюция ассоциативна — свернуть сигнал A с IR X, затем с IR Y — то же самое, что свернуть A с одной IR, которая есть X, свёрнутая с Y. Так что для комбинирования двух IR:

  1. Запустите TaraDSP с IR X в качестве входа и IR Y в качестве импульсной характеристики
  2. Выход — новый WAV, который есть комбинированная IR
  3. Используйте этот комбинированный WAV как обычную IR в любой свёртке

Пример: Смешать два IR кабинета

TaraDSP -x cab_close.wav -y cab_room.wav -o cab_blend.wav -b 32 --min

Это сворачивает cab_close.wav с cab_room.wav, создавая cab_blend.wav — новую IR, которая звучит как каб, микрофонированный вблизи, сыгранный в комнате. Используйте --min, чтобы сохранить минимальную фазу, и -b 32 для вывода float (без потери качества).

Пример: Запечь EQ в IR каба

TaraDSP -x cab_ir.wav -y eq_curve.wav -o cab_eq.wav -b 32 --min

Сворачивает IR каба с кривой EQ (как IR), запекая EQ в каб. Результат — новая IR каба с применённым EQ.

Пример: Смесь двух кабов с контролем уровня

TaraDSP -x cab_a.wav -y cab_b.wav -o cab_ab.wav -b 32 --min -l 2048

Комбинирует две IR каба и обрезает до 2048 сэмплов для использования в модельерах. Относительная громкость двух кабов зависит от их исходных уровней — при необходимости сначала нормализуйте входные IR.

Совет: Всегда используйте -b 32 (32-битный float) для комбинирования IR — это сохраняет полный динамический диапазон без квантования. Снижайте до 16/24 бит только для финального вывода после завершения всей обработки.
Совет: Используйте --min при комбинировании IR для симуляции кабинета — это убирает pre-ringing на каждом этапе и сохраняет результат плотным.

11. Советы из Траншеи

Выбор IR

  • Короче = плотнее: IR 0.5с имеет меньше низкочастотного гула, чем 2с
  • Позиция микрофона важна: по оси = ярко, вне оси = темно
  • Расстояние добавляет комнату: вблизи = сухо, в комнате = просторно
  • Минимальная фаза почти всегда лучше для кабов

Управление Уровнями

  • Нормализуйте после свёртки, а не до
  • Используйте 24 бита везде — дизеринг только на финальном выводе
  • Проверяйте моно-совместимость — стерео IR могут иметь проблемы с фазой

Распространённые Ошибки

  • Линейно-фазовые IR для кабов — всегда используйте --min
  • Дизеринг несколько раз — делайте дизеринг один раз, в конце
  • Забыть нормализовать — свёртка может поднять на 6-12 дБ
  • 16 бит для промежуточных файлов — используйте 24 или 32 бита
