Что такое TaraDSP?

TaraDSP — это профессиональный инструмент обработки аудио, который применяет конволюцию на основе БПФ с импульсными характеристиками, выполняет ресемплинг аудио и применяет дизеринг и фейды мастеринг-класса. Он предназначен для музыкантов, звукоинженеров и разработчиков, которым нужны результаты студийного качества от лёгкого кроссплатформенного инструмента командной строки.

БПФ-конволюция

Высокоскоростная конволюция с использованием библиотеки PFFFT (Pretty Fast FFT). Сверните любой аудиосигнал с импульсными характеристиками кабинета, IR реверберации или пользовательскими фильтрами за считанные секунды.

Мультиплатформенность

Нативные бинарники для Windows (x86_64), macOS (Intel + Apple Silicon) и Linux (x86_64 + ARM). Один инструмент для всех платформ.

Мастеринг-дизеринг

Дизеринг TPDF (Треугольная функция плотности вероятности) с обратной связью по ошибке для прозрачного вывода 16 и 24 бита.

Ресемплинг

Высококачественное преобразование частоты дискретизации через SoX Resampler (libsoxr) с резервной линейной интерполяцией. Конвертируйте между любыми частотами.

Минимальная фаза

Преобразуйте импульсные характеристики с линейной фазой в минимальную фазу для меньшей задержки и более естественного звучания.

Кроссплатформенная сборка

Автоматизированный CI/CD с GitHub Actions. Цепочка инструментов на основе fpcupdeluxe автоматически устанавливает FPC, Lazarus и все кросс-компиляторы.

Быстрый старт

Примените импульсную характеристику к аудиофайлу:

TaraDSP -x input.wav -y impulse_response.wav -o output.wav

Конвертируйте в 24 бита с ресемплингом:

TaraDSP -x input.wav -y ir.wav -o output.wav -b 24 -r 48000

Примените фейды и обрежьте тишину:

TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60
