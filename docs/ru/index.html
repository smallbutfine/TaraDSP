What is TaraDSP?

TaraDSP is a professional audio processing tool that applies FFT-based convolution with impulse responses, resamples audio, and applies mastering-grade dithering and fades. It is designed for musicians, audio engineers, and developers who need studio-quality results from a lightweight, cross-platform command-line tool.

FFT Convolution

High-speed convolution using the PFFFT library (Pretty Fast FFT). Convolve any audio signal with cabinet impulse responses, reverb IRs, or custom filters in seconds.

Multi-Platform

Native binaries for Windows (x86_64), macOS (Intel + Apple Silicon), and Linux (x86_64 + ARM). One tool, every platform.

Mastering Dither

TPDF (Triangular Probability Density Function) dithering with error feedback for transparent 16-bit and 24-bit output.

Resampling

High-quality sample rate conversion via SoX Resampler (libsoxr) with fallback to linear interpolation. Convert between any rates.

Minimum Phase

Convert linear-phase impulse responses to minimum phase for lower latency and more natural sound.

Cross-Platform Build

Automated CI/CD with GitHub Actions. fpcupdeluxe-based toolchain installs FPC, Lazarus, and all cross-compilers automatically.

Quick Start

Apply an impulse response to an audio file:

TaraDSP -x input.wav -y impulse_response.wav -o output.wav

Convert to 24-bit with resampling:

TaraDSP -x input.wav -y ir.wav -o output.wav -b 24 -r 48000

Apply fades and trim silence:

TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60
