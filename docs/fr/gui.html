Interface Graphique Utilisateur

La GUI de TaraDSP fournit le même traitement audio professionnel que la CLI dans une fenêtre facile à utiliser. C'est la façon recommandée de traiter les fichiers de manière interactive.

Contrôles

ContrôleTypeDescription
Fichier Source Sélecteur de fichier Le fichier WAV d'entrée à traiter. Cliquez pour parcourir un fichier.
Réponse Impulsionnelle Sélecteur de fichier Le fichier WAV IR avec lequel convoluer. Laissez vide pour le mode passage direct (mastering seulement : dither, normaliser, fondus).
Fichier de Sortie Texte + parcourir Le chemin du fichier WAV de sortie. Cliquez sur « ... » pour parcourir un emplacement.
Profondeur de Bits Combo : 16 / 24 / 32 Profondeur de bits de sortie. 24 est recommandé pour la qualité studio. 16 applique un dithering TPDF. 32 sort en IEEE float.
Fréquence d'Échantillonnage Combo Fréquence d'échantillonnage cible : 0 (garder l'original), 44100, 48000, 88200, 96000, 176400, 192000. L'entrée et l'IR sont rééchantillonnées si nécessaire.
Longueur de Troncature Spin edit Échantillons de sortie maximum. 0 = pas de limite. Utile pour les modéliseurs de guitare (p. ex. 1024 pour GP-200). Un fondu de sortie court est appliqué au point de troncature pour éviter les clics.
Fondu de Sortie Spin edit (ms) Durée du fondu de sortie appliqué à l'IR avant la convolution. Un fondu d'entrée de 1ms est toujours appliqué pour éviter les clics de début.
Couper le Silence Spin edit (dB) Seuil en dessous duquel les échantillons sont considérés comme du silence et supprimés de l'IR. Mettez 0 pour désactiver. Typique : -60 à -80.
Sortie Mono Case à cocher Mixer la sortie vers un seul canal.
Phase Minimale Case à cocher Convertir la sortie convoluée en phase minimale. Supprime le pre-ringing et réduit la latence.
PROCESS Bouton Exécuter le pipeline de traitement. La progression est affichée dans le journal.
Journal Memo en lecture seule Affiche la progression par étape : chargement, rééchantillonnage, convolution, normalisation, sauvegarde. Les erreurs sont affichées en texte rouge.

Pipeline de Traitement

Lorsque vous cliquez sur PROCESS, la GUI exécute les étapes suivantes dans l'ordre :

  1. Charger l'entrée — Lire le fichier WAV source (PCM ou float 8/16/24/32 bits)
  2. Charger l'IR — Lire la réponse impulsionnelle (si spécifiée)
  3. Couper le silence — Supprimer le silence sous le seuil de l'IR (si défini)
  4. Appliquer le fondu — Appliquer un fondu de sortie à l'IR (si défini)
  5. Rééchantillonner — Rééchantillonner l'entrée et l'IR à la fréquence cible (si définie)
  6. Convoluer — Convolution FFT par canal
  7. Phase minimale — Convertir en phase minimale (si coché)
  8. Normaliser — Normaliser le pic à 1.0
  9. Tronquer — Tronquer à la longueur max (si définie)
  10. Sauver — Écrire le WAV de sortie avec dithering (16 bits) ou float (32 bits)

Astuces

Astuce 1 : Laissez le champ IR vide pour utiliser la GUI comme un outil de mastering — elle appliquera le dither, normalisera et appliquera des fondus sans convolution.
Astuce 2 : Pour la simulation de haut-parleur de guitare, réglez la longueur de troncature à 1024 ou 2048 échantillons et activez la phase minimale pour le son le plus serré et à la plus faible latence.
Astuce 3 : Utilisez une sortie 24 bits pour le meilleur équilibre entre qualité et taille de fichier. Le 16 bits n'est nécessaire que pour la compatibilité CD.
Astuce 4 : La GUI lit settings.ini du même répertoire que l'exécutable pour les valeurs par défaut (nom d'artiste, profondeur de bits, quantité de dither, longueur de troncature).

Fichier de Configuration

La GUI lit un fichier settings.ini pour les valeurs par défaut :

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
