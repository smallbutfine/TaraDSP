Téléchargements

Les binaires précompilés sont joints à chaque Release GitHub :

PlateformeArtefactNotes
Windows 64 bits TaraDSP_<version>_Setup.exe Installateur Inno Setup. Inclut la GUI, la CLI, libpffft.dll et la config.
macOS Intel TaraDSP_gui<version>-macos-intel.zip Bundle d'app universel. Décompressez et glissez vers /Applications.
macOS Apple Silicon TaraDSP_gui<version>-macos-aarch64.zip Bundle d'app universel. Décompressez et glissez vers /Applications.
Linux x86_64 TaraDSP<version>-linux-x64.tar.gz Extrayez et lancez. Inclut libpffft.so.
Linux ARM TaraDSP<version>-linux-arm.tar.gz Extrayez et lancez. Inclut libpffft.so.
macOS : L'app n'est pas signée. Au premier lancement, utilisez clic droit → Ouvrir (ou xattr -dr com.apple.quarantine dans le Terminal).
Linux : L'archive inclut la bibliothèque partagée libpffft.so. Assurez-vous qu'elle se trouve à côté de l'exécutable TaraDSP, ou définissez LD_LIBRARY_PATH en conséquence.

Compilation depuis les Sources

Voir la Documentation pour les instructions de compilation. En bref :

./build_all.bat            # les 5 cibles + paquets dans Deploy/
./build_all.bat --check    # vérifier la chaîne d'outils uniquement
