Downloads

Prebuilt binaries are attached to every GitHub Release:

PlatformArtifactNotes
Windows 64-bit TaraDSP_<version>_Setup.exe Inno Setup installer. Includes GUI, CLI, libpffft.dll, and config.
macOS Intel TaraDSP_gui<version>-macos-intel.zip Universal app bundle. Unzip and drag to /Applications.
macOS Apple Silicon TaraDSP_gui<version>-macos-aarch64.zip Universal app bundle. Unzip and drag to /Applications.
Linux x86_64 TaraDSP<version>-linux-x64.tar.gz Extract and run. Includes libpffft.so.
Linux ARM TaraDSP<version>-linux-arm.tar.gz Extract and run. Includes libpffft.so.
macOS: The app is not code-signed. On first launch, use right-click → Open (or xattr -dr com.apple.quarantine in Terminal).
Linux: The tarball includes the libpffft.so shared library. Make sure it sits next to the TaraDSP executable, or set LD_LIBRARY_PATH accordingly.

Building from Source

See the Documentation for build instructions. In short:

./build_all.bat            # all 5 targets + packages into Deploy/
./build_all.bat --check    # verify the toolchain only
