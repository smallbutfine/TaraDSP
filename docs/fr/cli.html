Référence de la Ligne de Commande

L'exécutable TaraDSP est un outil de traitement audio en ligne de commande. Il applique une convolution FFT avec des réponses impulsionnelles, rééchantillonne l'audio et applique un dithering et des fondus de mastering.

Démarrage rapide

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Options

OptionForme longueValeurDescription
-x --in1 <fichier> Fichier WAV d'entrée (le signal audio à traiter)
-y --in2 <fichier> Fichier WAV de réponse impulsionnelle (facultatif — si omis, une impulsion unitaire est utilisée, produisant un passage avec mastering)
-o --output <fichier> Fichier WAV de sortie
-b --bits 16|24|32 Profondeur de bits de sortie (par défaut : 24)
-r --rate <Hz> Fréquence d'échantillonnage cible (p. ex. 44100, 48000, 96000). Si définie, l'entrée et l'IR sont rééchantillonnées à cette fréquence.
-l --length <échantillons> Tronquer la sortie à ce nombre d'échantillons (0 = pas de troncature)
-t --trim <dB> Couper le silence sous ce seuil (p. ex. -60). Appliqué à l'IR avant la convolution.
-f --fade <ms> Appliquer un fondu de sortie de cette durée en millisecondes à l'IR. Un fondu d'entrée de 1ms est toujours appliqué.
-m --mono (drapeau) Forcer une sortie mono (mixage vers un seul canal)
--min (drapeau) Convertir la sortie convoluée en phase minimale
-h --help (drapeau) Afficher l'aide et les informations d'utilisation

Exemples

Convolution de base

Convoluer un signal de guitare avec une réponse impulsionnelle de haut-parleur :

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Mastering avec dithering

Appliquer le mastering à un mixage sans convolution (sans IR), sortie 16 bits avec dithering :

TaraDSP -x mix.wav -o master.wav -b 16

Rééchantillonnage

Convertir un fichier 44,1 kHz en 48 kHz avec convolution :

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Conversion en phase minimale

Convertir une IR à phase linéaire en phase minimale pour une latence plus faible :

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Couper le silence et appliquer un fondu

Couper le silence sous -60 dB de l'IR, appliquer un fondu de sortie de 50 ms :

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Sortie mono

Mixer la stéréo vers le mono :

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Tronquer pour les modéliseurs

Tronquer à 1024 échantillons (pour les modéliseurs de guitare comme le GP-200) :

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

Astuce : Pour de meilleurs résultats, utilisez une sortie 24 bits. Elle offre plus de marge que le 16 bits et est plus légère que le 32 bits flottant. Le dither de mastering n'est appliqué que pour la sortie 16 bits.

Fichier de Configuration

TaraDSP lit un fichier settings.ini du même répertoire que l'exécutable (ou du répertoire de travail actuel). Ce fichier peut définir des valeurs par défaut pour les métadonnées d'artiste, la profondeur de bits, la quantité de dither, et plus encore.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
