Downloads

Os binários pré-compilados são anexados a cada Release do GitHub:

PlataformaArtefatoNotas
Windows 64 bits TaraDSP_<version>_Setup.exe Instalador Inno Setup. Inclui GUI, CLI, libpffft.dll e configuração.
macOS Intel TaraDSP_gui<version>-macos-intel.zip Bundle de app universal. Descompacte e arraste para /Applications.
macOS Apple Silicon TaraDSP_gui<version>-macos-aarch64.zip Bundle de app universal. Descompacte e arraste para /Applications.
Linux x86_64 TaraDSP<version>-linux-x64.tar.gz Extraia e execute. Inclui libpffft.so.
Linux ARM TaraDSP<version>-linux-arm.tar.gz Extraia e execute. Inclui libpffft.so.
macOS: O app não é assinado por código. No primeiro lançamento, use clique direito → Abrir (ou xattr -dr com.apple.quarantine no Terminal).
Linux: O tarball inclui a biblioteca compartilhada libpffft.so. Certifique-se de que ela fique ao lado do executável TaraDSP, ou defina LD_LIBRARY_PATH adequadamente.

Compilação a partir do Código-Fonte

Veja a Documentação para as instruções de compilação. Resumindo:

./build_all.bat            # os 5 alvos + pacotes em Deploy/
./build_all.bat --check    # verificar apenas a cadeia de ferramentas
