TARADSP

Convolução de Áudio e Masterização Profissional — FreePascal / Lazarus

Convolução de resposta ao impulso de qualidade de estúdio, reamostragem e masterização — em uma única ferramenta de linha de comando.

Início Conceitos Referência CLI GUI Documentação Manual Baixar DE ES FR PT RU ZH

O que é o TaraDSP?

O TaraDSP é uma ferramenta profissional de processamento de áudio que aplica convolução baseada em FFT com respostas ao impulso, reamostra áudio, e aplica dithering e fades de qualidade de masterização. É projetado para músicos, engenheiros de áudio e desenvolvedores que precisam de resultados de qualidade de estúdio de uma ferramenta de linha de comando leve e multiplataforma.

Convolução FFT

Convolução de alta velocidade usando a biblioteca PFFFT (Pretty Fast FFT). Convolua qualquer sinal de áudio com respostas ao impulso de cabinet, IRs de reverb ou filtros personalizados em segundos.

Multiplataforma

Binários nativos para Windows (x86_64), macOS (Intel + Apple Silicon), e Linux (x86_64 + ARM). Uma ferramenta, todas as plataformas.

Dither de Masterização

Dithering TPDF (Função de Densidade de Probabilidade Triangular) com realimentação de erro para saída transparente de 16 e 24 bits.

Remostragem

Conversão de taxa de amostragem de alta qualidade via SoX Resampler (libsoxr) com fallback para interpolação linear. Converta entre quaisquer taxas.

Fase Mínima

Converta respostas ao impulso de fase linear para fase mínima para menor latência e som mais natural.

Build Multiplataforma

CI/CD automatizado com GitHub Actions. A cadeia de ferramentas baseada em fpcupdeluxe instala FPC, Lazarus e todos os compiladores cruzados automaticamente.

Início Rápido

Aplique uma resposta ao impulso a um arquivo de áudio:

TaraDSP -x input.wav -y impulse_response.wav -o output.wav

Converta para 24 bits com reamostragem:

TaraDSP -x input.wav -y ir.wav -o output.wav -b 24 -r 48000

Aplique fades e corte o silêncio:

TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60
