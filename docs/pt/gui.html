Interface Gráfica do Usuário

A GUI do TaraDSP fornece o mesmo processamento de áudio profissional que a CLI em uma janela fácil de usar. É a forma recomendada de processar arquivos interativamente.

Controles

ControleTipoDescrição
Arquivo de Origem Seletor de arquivo O arquivo WAV de entrada a processar. Clique para navegar por um arquivo.
Resposta ao Impulso Seletor de arquivo O arquivo WAV de IR com o qual convoluir. Deixe vazio para o modo passagem direta (apenas masterização: dither, normalizar, fades).
Arquivo de Saída Texto + navegar O caminho do arquivo WAV de saída. Clique em "..." para navegar por um local.
Profundidade de Bits Combo: 16 / 24 / 32 Profundidade de bits de saída. 24 é recomendado para qualidade de estúdio. 16 aplica dithering TPDF. 32 gera IEEE float.
Taxa de Amostragem Combo Taxa de amostragem alvo: 0 (manter original), 44100, 48000, 88200, 96000, 176400, 192000. Tanto a entrada quanto o IR são reamostrados se necessário.
Comprimento de Truncamento Spin edit Máximo de amostras de saída. 0 = sem limite. Útil para modeladores de guitarra (ex. 1024 para GP-200). Um fade-out curto é aplicado no ponto de truncamento para evitar cliques.
Fade-Out Spin edit (ms) Duração do fade-out aplicado ao IR antes da convolução. Um fade-in de 1ms é sempre aplicado para evitar cliques no início.
Cortar Silêncio Spin edit (dB) Limiar abaixo do qual as amostras são consideradas silêncio e removidas do IR. Defina 0 para desativar. Típico: -60 a -80.
Saída Mono Caixa de seleção Mixar a saída para um único canal.
Fase Mínima Caixa de seleção Converter a saída convoluída para fase mínima. Remove o pre-ringing e reduz a latência.
PROCESS Botão Executar o pipeline de processamento. O progresso é mostrado no log.
Log Memo somente leitura Mostra o progresso por etapa: carregando, reamostrando, convoluindo, normalizando, salvando. Erros são mostrados em texto vermelho.

Pipeline de Processamento

Quando você clica em PROCESS, a GUI executa as seguintes etapas em ordem:

  1. Carregar entrada — Ler o arquivo WAV de origem (PCM ou float de 8/16/24/32 bits)
  2. Carregar IR — Ler a resposta ao impulso (se especificada)
  3. Cortar silêncio — Remover o silêncio abaixo do limiar do IR (se definido)
  4. Aplicar fade — Aplicar fade-out ao IR (se definido)
  5. Remostrar — Reamostrar entrada e IR para a taxa alvo (se definida)
  6. Convoluir — Convolução FFT por canal
  7. Fase mínima — Converter para fase mínima (se marcado)
  8. Normalizar — Normalizar o pico para 1.0
  9. Truncar — Truncar para o comprimento máximo (se definido)
  10. Salvar — Gravar o WAV de saída com dithering (16 bits) ou float (32 bits)

Dicas

Dica 1: Deixe o campo de IR vazio para usar a GUI como uma ferramenta de masterização — ela aplicará dither, normalizará e aplicará fades sem convolução.
Dica 2: Para simulação de cabinet de guitarra, defina o comprimento de truncamento para 1024 ou 2048 amostras e ative a fase mínima para o som mais apertado e de menor latência.
Dica 3: Use saída de 24 bits para o melhor equilíbrio entre qualidade e tamanho de arquivo. 16 bits só é necessário para compatibilidade com CD.
Dica 4: A GUI lê settings.ini do mesmo diretório que o executável para valores padrão (nome do artista, profundidade de bits, quantidade de dither, comprimento de truncamento).

Arquivo de Configuração

A GUI lê um arquivo settings.ini para valores padrão:

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
