Referência de Linha de Comando

O executável TaraDSP é uma ferramenta de processamento de áudio de linha de comando. Aplica convolução FFT com respostas ao impulso, reamostra áudio, e aplica dithering e fades de masterização.

Início rápido

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Opções

OpçãoForma longaValorDescrição
-x --in1 <arquivo> Arquivo WAV de entrada (o sinal de áudio a processar)
-y --in2 <arquivo> Arquivo WAV de resposta ao impulso (opcional — se omitido, um impulso unitário é usado, produzindo uma passagem direta com masterização)
-o --output <arquivo> Arquivo WAV de saída
-b --bits 16|24|32 Profundidade de bits de saída (padrão: 24)
-r --rate <Hz> Taxa de amostragem alvo (ex. 44100, 48000, 96000). Se definida, tanto a entrada quanto o IR são reamostrados para esta taxa.
-l --length <amostras> Truncar a saída para este número de amostras (0 = sem truncamento)
-t --trim <dB> Cortar o silêncio abaixo deste limiar (ex. -60). Aplicado ao IR antes da convolução.
-f --fade <ms> Aplicar um fade-out desta duração em milissegundos ao IR. Um fade-in de 1ms é sempre aplicado.
-m --mono (flag) Forçar saída mono (mixar para um único canal)
--min (flag) Converter a saída convoluída para fase mínima
-h --help (flag) Mostrar ajuda e informações de uso

Exemplos

Convolução básica

Convoluir um sinal de guitarra com uma resposta ao impulso de cabinet:

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Masterização com dithering

Aplicar masterização a uma mixagem sem convolução (sem IR), saída de 16 bits com dithering:

TaraDSP -x mix.wav -o master.wav -b 16

Remostragem

Converter um arquivo de 44.1kHz para 48kHz com convolução:

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Conversão para fase mínima

Converter um IR de fase linear para fase mínima para menor latência:

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Cortar silêncio e aplicar fade

Cortar o silêncio abaixo de -60dB do IR, aplicar um fade-out de 50ms:

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Saída mono

Mixar estéreo para mono:

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Truncar para modeladores

Truncar para 1024 amostras (para modeladores de guitarra como GP-200):

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

Formatos de Saída

Profundidade de BitsFormatoDitheringNotas
16 bitsWAV (PCM)TPDF com realimentação de erroQualidade de CD, universalmente compatível
24 bitsWAV (PCM)Nenhum (resolução nativa)Qualidade de estúdio, recomendado
32 bitsWAV (IEEE Float)NenhumFaixa dinâmica máxima, para processamento adicional
Dica: Para melhores resultados, use saída de 24 bits. Ela oferece mais margem que 16 bits e é menor que 32 bits float. O dither de masterização só é aplicado para saída de 16 bits.

Arquivo de Configuração

O TaraDSP lê um arquivo settings.ini do mesmo diretório que o executável (ou do diretório de trabalho atual). Este arquivo pode definir valores padrão para metadados de artista, profundidade de bits, quantidade de dither e mais.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
