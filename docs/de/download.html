Downloads

Vorkompilierte Binaries sind an jedem GitHub Release angehängt:

PlattformArtifactHinweise
Windows 64-bitTaraDSP_<version>_Setup.exeInno Setup Installer. Enthält CLI, GUI und Konfigurationsdateien.
macOS IntelTaraDSP<version>-macos-intel.zipUniverselles App-Bundle. Entpacken und nach Programme ziehen.
macOS Apple SiliconTaraDSP<version>-macos-aarch64.zipUniverselles App-Bundle. Entpacken und nach Programme ziehen.
Linux x86_64TaraDSP<version>-linux-x64.tar.gzEntpacken und ausführen. Keine Abhängigkeiten.
Linux ARMTaraDSP<version>-linux-arm.tar.gzEntpacken und ausführen. Keine Abhängigkeiten.
macOS: Die App ist nicht code-signiert. Beim ersten Start Rechtsklick → Öffnen verwenden (oder xattr -dr com.apple.quarantine im Terminal).

Aus Quellcode bauen

./build_all.bat            # alle 5 Ziele + Pakete in Deploy/
./build_all.bat --check    # nur Toolchain überprüfen
