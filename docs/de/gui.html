Grafische Oberfläche

Die TaraDSP-GUI bietet dieselbe professionelle Audio-Verarbeitung wie die CLI in einem einfach zu bedienenden Fenster. Sie ist die empfohlene Methode zur interaktiven Dateiverarbeitung.

Bedienelemente

BedienelementTypBeschreibung
Quelldatei Dateiauswahl Die zu verarbeitende Eingabe-WAV-Datei. Klicken, um eine Datei zu suchen.
Impulsantwort Dateiauswahl Die IR-WAV-Datei zum Falten. Leer lassen für Durchgangmodus (nur Mastering: Dither, Normalisieren, Fades).
Ausgabedatei Text + Durchsuchen Der Pfad zur Ausgabe-WAV-Datei. Auf "..." klicken, um einen Speicherort zu suchen.
Bittiefe Combo: 16 / 24 / 32 Ausgabe-Bittiefe. 24 wird für Studio-Qualität empfohlen. 16 wendet TPDF-Dithering an. 32 gibt IEEE-Float aus.
Samplerate Combo Ziel-Samplerate: 0 (Original beibehalten), 44100, 48000, 88200, 96000, 176400, 192000. Sowohl Eingabe als auch IR werden bei Bedarf resampelt.
Länge kürzen Spin-Edit Maximale Ausgabe-Samples. 0 = kein Limit. Nützlich für Gitarrenmodeler (z. B. 1024 für GP-200). Ein kurzer Fade-Out wird an der Kürzungsstelle angewendet, um Klicks zu verhindern.
Fade-Out Spin-Edit (ms) Dauer des auf die IR vor der Faltung angewendeten Fade-Outs. Ein 1ms Fade-In wird immer angewendet, um Startklicks zu verhindern.
Stille schneiden Spin-Edit (dB) Schwellenwert, unter dem Samples als Stille betrachtet und aus der IR entfernt werden. Auf 0 setzen, um zu deaktivieren. Typisch: -60 bis -80.
Mono-Ausgabe Checkbox Ausgabe auf einen einzelnen Kanal downmixen.
Minimum Phase Checkbox Die gefaltete Ausgabe zu Minimum Phase konvertieren. Entfernt Pre-Ringing und reduziert Latenz.
PROCESS Schaltfläche Startet die Verarbeitungspipeline. Fortschritt wird im Log angezeigt.
Log Schreibgeschütztes Memo Zeigt Fortschritt pro Schritt: Laden, Resampling, Falten, Normalisieren, Speichern. Fehler werden in rotem Text angezeigt.

Verarbeitungspipeline

Wenn du auf PROCESS klickst, führt die GUI die folgenden Schritte der Reihe nach aus:

  1. Eingabe laden — Quelldatei lesen (8/16/24/32-Bit PCM oder Float)
  2. IR laden — Impulsantwort lesen (falls angegeben)
  3. Stille schneiden — Stille unter Schwellenwert aus IR entfernen (falls gesetzt)
  4. Fade anwenden — Fade-Out auf IR anwenden (falls gesetzt)
  5. Resamplen — Eingabe und IR auf Zielrate resamplen (falls gesetzt)
  6. Falten — FFT-Faltung pro Kanal
  7. Minimum Phase — Zu Minimum Phase konvertieren (falls aktiviert)
  8. Normalisieren — Peak auf 1.0 normalisieren
  9. Kürzen — Auf Maximallänge kürzen (falls gesetzt)
  10. Speichern — Ausgabe-WAV mit Dithering (16-Bit) oder Float (32-Bit) schreiben

Tipps

Tipp 1: IR-Feld leer lassen, um die GUI als Mastering-Werkzeug zu verwenden — es wendet Dither, Normalisierung und Fades ohne Faltung an.
Tipp 2: Für Gitarrenbox-Simulation die Kürzungslänge auf 1024 oder 2048 Samples setzen und Minimum Phase für den kompaktesten, latenzärmsten Klang aktivieren.
Tipp 3: 24-Bit-Ausgabe für die beste Balance aus Qualität und Dateigröße verwenden. 16-Bit wird nur für CD-Kompatibilität benötigt.
Tipp 4: Die GUI liest settings.ini aus dem Verzeichnis der ausführbaren Datei für Standardwerte (Künstlername, Bittiefe, Dither-Menge, Kürzungslänge).

Konfigurationsdatei

Die GUI liest eine settings.ini-Datei für Standardwerte:

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
