1. Was ist TaraDSP?

TaraDSP ist ein professionelles Audio-Verarbeitungswerkzeug, das eine Sache außergewöhnlich gut kann: FFT-basierte Faltung. Wenn du schon einmal einen Gitarrenbox-Simulator, ein Faltungshall oder eine Mastering-Kette mit analogem EQ verwendet hast, hast du Faltung benutzt.

TaraDSP gibt dir diese Leistung in einem schlanken, plattformübergreifenden Paket. Windows, macOS, Linux. CLI für Stapelverarbeitung, GUI für interaktive Arbeit.

2. Die Wissenschaft der Faltung

Was Faltung bewirkt

Faltung wendet die klanglichen Eigenschaften eines Signals (die Impulsantwort) auf ein anderes (dein Audio) an. Wenn du eine trockene Gitarre durch eine Box spielst, färbt die Box den Klang — Resonanzen, Frequenzgang, Abklingverhalten. Faltung wendet diese Färbung mathematisch an.

Warum FFT?

Direkte Faltung ist O(n²) — Milliarden von Operationen für eine 1-Sekunden-Datei. Die FFT reduziert dies auf O(n log n) durch den Faltungssatz:

Faltung im Zeitbereich = Multiplikation im Frequenzbereich

1. FFT beider Signale → Frequenzbereich

2. Multiplizieren → eine Multiplikation pro Bin

3. Inverse FFT → zurück in den Zeitbereich

5000× schneller. PFFFT beschleunigt weiter mit SIMD (SSE/NEON) — 4-8 Samples pro Instruktion.

3. Impulsantworten: Die klangliche DNA

Eine Impulsantwort ist eine Aufnahme eines Klicks durch ein System, die dessen vollständigen klanglichen Fingerabdruck erfasst.

TypErfasstLängeAnwendungsfall
Box-IRLautsprecher + Box + Mikrofon0,5–2sGitarren-/Bass-Box-Simulation
Raum-IRRaumakustik1–4sFaltungshall
Hardware-IREQ, Kompressor, Band0,1–1sAnalog-Gear-Emulation
Plate/Spring-IRMechanischer Hall1–3sVintage-Hall

Wo man sie findet: Kostenlose IR-Bibliotheken (Guitar Hack, God's Cab, Seacow), kommerzielle (Celestion, Redwirez, York Audio) oder DIY (Klick durch deine Box, mit einem Mikrofon aufnehmen).

4. Die Verarbeitungskette

Wenn du TaraDSP ausführst, durchläuft das Audio diese Kette. Jeder Schritt ist optional.

Schritt 1: Eingabe laden

Liest WAV (8/16/24/32-Bit PCM oder Float), konvertiert intern zu 32-Bit-Float.

Schritt 2: IR laden (optional)

Wenn keine IR angegeben → Durchgangmodus (nur Mastering: Dither, Normalisieren, Fades).

Schritt 3: Stille schneiden (optional)

-t <dB> — entfernt Stille unter Schwellenwert aus der IR. Typisch: -60 dB.

Schritt 4: Fades anwenden (optional)

-f <ms> — Fade-Out auf IR. Wendet immer 1ms Fade-In an (Klick-Vermeidung).

Schritt 5: Resamplen (optional)

-r <Hz> — resampelt Eingabe + IR auf Zielrate. Engine-Priorität: SoX (libsoxr) → R8Brain → FinalCD → linear.

Schritt 6: Falten

FFT-Faltung über PFFFT. Ausgabelänge = Eingabe + IR - 1 Samples.

Schritt 7: Minimum Phase (optional)

--min — entfernt Pre-Ringing, reduziert Latenz. Verwendet die Real-Cepstrum-Methode.

Schritt 8: Normalisieren

Peak auf 1.0 (0 dBFS) normalisieren.

Schritt 9: Kürzen (optional)

-l <samples> — Ausgabelänge begrenzen. Für Modeler: 1024 (GP-200), 2048 (Helix).

Schritt 10: Dithern und Speichern

-b <16|24|32> — 16-Bit erhält TPDF-Dither + Fehlerrückführung. 24/32-Bit: kein Dither.

5. Mastering-Dither

Das Problem

Quantisierung von 24-Bit auf 16-Bit ohne Dither erzeugt harmonische Verzerrungen bei niedrigen Pegeln.

Die Lösung: TPDF

Fügt 2 LSB dreieckiges Rauschen vor der Quantisierung hinzu. Wandelt Verzerrung in einen konstanten Pegelboden um — weniger hörbar, natürlicher.

TaraDSPs Implementierung:

  • TPDF-Rauschen: Zwei Zufallswerte summiert (dreieckige Verteilung)
  • Fehlerrückführung: Quantisierungsfehler zurückgeführt, formt das Rauschspektrum
  • Signalabhängige Skalierung: 70% Dither bei sehr niedrigen Pegeln (< -90 dBFS)

Wann verwenden

  • Immer für 16-Bit dithern — immer besser als Kürzung
  • Niemals für 24/32-Bit dithern — Quantisierungsfehler liegt unter dem Pegelboden
  • Einmal dithern — nur in der finalen Ausgabestufe

6. Minimum Phase

Pre-Ringing

Linearphasige IRs haben symmetrische Energie — vor UND nach dem Hauptimpuls. Die Energie davor ist Pre-Ringing, das unnatürlich klingt (in der Natur kommt Schall nach, nie davor).

Was Minimum Phase bewirkt

Transformiert eine linearphasige IR zu Minimum Phase:

  • Kein Pre-Ringing
  • Niedrigere Latenz
  • Gleicher Frequenzgang (Magnitude unverändert)

Algorithmus

Real-Cepstrum-Methode: FFT → Log-Magnitude → inverse FFT (Cepstrum) → Falten → FFT → komplexes Spektrum → inverse FFT.

Wann verwenden

  • Immer für Boxensimulation — entfernt den "hohlen" Klang
  • Immer für Echtzeit — niedrigere Latenz
  • Optional für Hall — manche bevorzugen linearphasige Räumlichkeit

7. Resampling

Warum

  • Nicht übereinstimmende Raten (44,1k IR, 48k Projekt)
  • Zielgerät erwartet bestimmte Rate
  • CD-Veröffentlichung (44,1k)

Aliasing

Heruntertasten ohne Filterung lässt Frequenzen über Nyquist als metallische Artefakte zurückfalten.

Engine-Priorität

1. SoX Resampler (libsoxr) — VHQ, korrekte Anti-Aliasing-Filterung. Beste Option.

2. R8Brain — VHQ, verwendet wenn libsoxr nicht verfügbar.

3. FinalCD — externes Tool.

4. Lineare Interpolation — Fallback, kein Anti-Aliasing.

libsoxr für beste Ergebnisse installieren. Wird als libsoxr.dll / .dylib / .so.0 ausgeliefert.

8. Fades und Kürzung

Stille schneiden

IRs haben oft Stille am Anfang/Ende. Kürzung entfernt sie:

  • -60 — typisch für IRs
  • -80 — aggressiv
  • 0 — deaktiviert

Fades

  • Fade-In: Immer 1ms (automatisch) — verhindert Startklicks
  • Fade-Out: Benutzerdefiniert (-f <ms>) — verhindert Endklicks

Linearer Verstärkungsramp: 1.0 → 0.0 (Fade-Out) oder 0.0 → 1.0 (Fade-In).

9. Praktische Workflows

Gitarrenbox-Simulation


TaraDSP -x guitar_di.wav -y cab_57.wav -o guitar_amped.wav --min -l 2048 -b 24

Faltungshall


TaraDSP -x vocal_dry.wav -y concert_hall.wav -o vocal_reverb.wav -f 100 -b 24

Mastering mit Dither


TaraDSP -x mix_24bit.wav -o master_16bit.wav -b 16

Samplerate-Konvertierung


TaraDSP -x recording_96k.wav -o master_44k1.wav -r 44100 -b 16

Stapelverarbeitung


for %f in (*.wav) do TaraDSP -x "%f" -y cab_ir.wav -o "processed_%f" --min -b 24

10. Tipps aus der Praxis

IR-Auswahl

  • Kürzer = kompakter: 0,5s IR hat weniger Bass-Grummeln als 2s
  • Mikrofonposition matters: On-Axis = hell, Off-Axis = dunkel
  • Abstand adds Raum: Nah mikrofoniert = trocken, Raum mikrofoniert = räumlich
  • Minimum Phase ist fast immer besser für Boxen

Pegelverwaltung

  • Nach der Faltung normalisieren, nicht davor
  • Durchgehend 24-Bit verwenden — Dither nur bei finaler Ausgabe
  • Mono-Kompatibilität prüfen — Stereo-IRs können Phasenprobleme haben

Häufige Fehler

  • Linearphasige IRs für Boxen — immer --min verwenden
  • Mehrfach dithern — einmal dithern, am Ende
  • Vergessen zu normalisieren — Faltung kann 6-12 dB verstärken
  • 16-Bit für Zwischendateien — 24-Bit oder 32-Bit verwenden
