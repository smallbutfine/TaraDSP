CLI-Referenz

Das TaraDSP-Programm ist ein Kommandozeilen-Audio-Verarbeitungswerkzeug. Es wendet FFT-Faltung mit Impulsantworten an, resampelt Audio und wendet Mastering-Dithering und Fades an.

Schnellstart

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

Optionen

OptionLangformWertBeschreibung
-x --in1 <file> Eingabe-WAV-Datei (das zu verarbeitende Audiosignal)
-y --in2 <file> Impulsantwort-WAV-Datei (optional — wenn weggelassen, wird eine Einheitsimpuls verwendet, was einem Durchgang mit Mastering entspricht)
-o --output <file> Ausgabe-WAV-Datei
-b --bits 16|24|32 Ausgabe-Bittiefe (Standard: 24)
-r --rate <Hz> Ziel-Samplerate (z. B. 44100, 48000, 96000). Wenn gesetzt, werden sowohl Eingabe als auch IR auf diese Rate resampelt.
-l --length <samples> Ausgabe auf diese Anzahl von Samples kürzen (0 = keine Kürzung)
-t --trim <dB> Schneidet Stille unter diesem Schwellenwert (z. B. -60). Wird auf die IR vor der Faltung angewendet.
-f --fade <ms> Wendet einen Fade-Out dieser Dauer in Millisekunden auf die IR an. Ein 1ms Fade-In wird immer angewendet.
-m --mono (Flag) Erzwingt Mono-Ausgabe (Downmix auf einen Kanal)
--min (Flag) Konvertiert die gefaltete Ausgabe zu Minimum Phase
-h --help (Flag) Zeigt Hilfe und Verwendungsinformationen

Beispiele

Einfache Faltung

Ein Gitarrensignal mit einer Box-Impulsantwort falten:

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

Mastering mit Dithering

Mastering auf einen Mix ohne Faltung anwenden (keine IR), 16-Bit-Ausgabe mit Dithering:

TaraDSP -x mix.wav -o master.wav -b 16

Resampling

Eine 44,1kHz-Datei mit Faltung auf 48kHz konvertieren:

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

Minimum-Phase-Konvertierung

Eine linearphasige IR zu Minimum Phase für geringere Latenz konvertieren:

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

Stille schneiden und Fade anwenden

Stille unter -60dB aus der IR schneiden, einen 50ms Fade-Out anwenden:

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

Mono-Ausgabe

Stereo auf Mono downmixen:

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

Für Modeler kürzen

Auf 1024 Samples kürzen (für Gitarrenmodeler wie GP-200):

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

BittiefeFormatDitheringHinweise

Tipp: Für die besten Ergebnisse 24-Bit-Ausgabe verwenden. Sie bietet mehr Headroom als 16-Bit und ist kleiner als 32-Bit-Float. Das Mastering-Dither wird nur für 16-Bit-Ausgabe angewendet.

Konfigurationsdatei

TaraDSP liest eine settings.ini-Datei aus demselben Verzeichnis wie die ausführbare Datei (oder dem aktuellen Arbeitsverzeichnis). Diese Datei kann Standardwerte für Künstlermetadaten, Bittiefe, Dither-Menge und mehr setzen.

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
