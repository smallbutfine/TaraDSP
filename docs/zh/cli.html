命令行参考

TaraDSP 可执行文件是一款命令行音频处理工具。 它采用脉冲响应进行 FFT 卷积，对音频进行重采样，并应用母带抖动和淡入淡出。

快速开始

TaraDSP -x input.wav -y impulse.wav -o output.wav
TaraDSP -x input.wav -o output.wav -b 24 -r 48000
TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60 --min

选项

选项长格式值说明
-x --in1 <文件> 输入 WAV 文件（要处理的音频信号）
-y --in2 <文件> 脉冲响应 WAV 文件（可选 — 如果省略，则使用单位脉冲，产生带母带处理的直通）
-o --output <文件> 输出 WAV 文件
-b --bits 16|24|32 输出位深（默认：24）
-r --rate <Hz> 目标采样率（例如 44100、48000、96000）。如果设置，输入和 IR 都会重采样到此采样率。
-l --length <采样> 将输出截断为此采样数（0 = 不截断）
-t --trim <dB> 修剪低于此阈值的静音（例如 -60）。在卷积前应用于 IR。
-f --fade <ms> 对此持续时长（毫秒）的 IR 应用淡出。始终会应用 1ms 的淡入。
-m --mono (标志) 强制单声道输出（下混为单声道）
--min (标志) 将卷积输出转换为最小相位
-h --help (标志) 显示帮助和使用信息

示例

基本卷积

将吉他信号与箱体脉冲响应进行卷积：

TaraDSP -x guitar.wav -y cab_ir.wav -o guitar_amped.wav

带抖动的母带处理

对混音应用母带处理而不进行卷积（无 IR），输出 16 位并带抖动：

TaraDSP -x mix.wav -o master.wav -b 16

重采样

将 44.1kHz 文件转换为 48kHz 并进行卷积：

TaraDSP -x input.wav -y ir.wav -o output.wav -r 48000

最小相位转换

将线性相位 IR 转换为最小相位以实现更低延迟：

TaraDSP -x input.wav -y linear_ir.wav -o output.wav --min

修剪静音并应用淡出

从 IR 中修剪低于 -60dB 的静音，应用 50ms 的淡出：

TaraDSP -x input.wav -y ir.wav -o output.wav -t -60 -f 50

单声道输出

将立体声下混为单声道：

TaraDSP -x stereo.wav -y ir.wav -o mono.wav -m

为建模器截断

截断为 1024 个采样（用于 GP-200 等吉他建模器）：

TaraDSP -x input.wav -y ir.wav -o output.wav -l 1024

输入格式

格式位深声道备注
WAV（PCM）8、16、24、32 位单声道、立体声、多声道支持所有标准 WAV 格式
WAV（IEEE 浮点）32 位浮点单声道、立体声完整动态范围，无削波

输出格式

位深格式抖动备注
16 位WAV（PCM）带误差反馈的 TPDFCD 品质，通用兼容
24 位WAV（PCM）无（原生分辨率）录音室品质，推荐
32 位WAV（IEEE 浮点）无最大动态范围，用于进一步处理
提示： 为获得最佳结果，请使用 24 位输出。 它比 16 位提供更多余量，且比 32 位浮点更小。母带 抖动仅适用于 16 位输出。

配置文件

TaraDSP 从可执行文件所在目录（或当前工作目录）读取 settings.ini 文件。此文件可为艺术家元数据、位深、 抖动量等设置默认值。

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
