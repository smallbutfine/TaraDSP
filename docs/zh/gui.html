Graphical User Interface

The TaraDSP GUI provides the same professional audio processing as the CLI in an easy-to-use window. It is the recommended way to process files interactively.

Controls

ControlTypeDescription
Source File File picker The input WAV file to process. Click to browse for a file.
Impulse Response File picker The IR WAV file to convolve with. Leave empty for passthrough mode (mastering only: dither, normalize, fades).
Output File Text + browse The output WAV file path. Click "..." to browse for a location.
Bit Depth Combo: 16 / 24 / 32 Output bit depth. 24 is recommended for studio quality. 16 applies TPDF dithering. 32 outputs IEEE float.
Sample Rate Combo Target sample rate: 0 (keep original), 44100, 48000, 88200, 96000, 176400, 192000. Both input and IR are resampled if needed.
Truncate Length Spin edit Maximum output samples. 0 = no limit. Useful for guitar modelers (e.g. 1024 for GP-200). A short fade-out is applied at the truncation point to prevent clicks.
Fade-Out Spin edit (ms) Duration of fade-out applied to the IR before convolution. A 1ms fade-in is always applied to prevent start clicks.
Trim Silence Spin edit (dB) Threshold below which samples are considered silence and removed from the IR. Set to 0 to disable. Typical: -60 to -80.
Mono Output Checkbox Downmix the output to a single channel.
Minimum Phase Checkbox Convert the convolved output to minimum phase. Removes pre-ringing and reduces latency.
PROCESS Button Run the processing pipeline. Progress is shown in the log.
Log Read-only memo Shows per-step progress: loading, resampling, convolving, normalizing, saving. Errors are shown in red text.

Processing Pipeline

When you click PROCESS, the GUI runs the following steps in order:

  1. Load input — Read the source WAV file (8/16/24/32-bit PCM or float)
  2. Load IR — Read the impulse response (if specified)
  3. Trim silence — Remove silence below threshold from IR (if set)
  4. Apply fade — Apply fade-out to IR (if set)
  5. Resample — Resample input and IR to target rate (if set)
  6. Convolve — FFT convolution per channel
  7. Minimum phase — Convert to minimum phase (if checked)
  8. Normalize — Peak normalize to 1.0
  9. Truncate — Truncate to max length (if set)
  10. Save — Write output WAV with dithering (16-bit) or float (32-bit)

Tips

Tip 1: Leave the IR field empty to use the GUI as a mastering tool — it will apply dither, normalize, and fades without convolution.
Tip 2: For guitar cabinet simulation, set the truncate length to 1024 or 2048 samples and enable minimum phase for the tightest, lowest-latency sound.
Tip 3: Use 24-bit output for the best balance of quality and file size. 16-bit is only needed for CD compatibility.
Tip 4: The GUI reads settings.ini from the same directory as the executable for default values (artist name, bit depth, dither amount, truncate length).

Configuration File

The GUI reads a settings.ini file for default values:

; settings.ini
[Metadata]
Artist=Your Studio Name

[Audio]
TargetBits=24
DitherAmount=1.0

[Hardware]
TruncateLen=0
