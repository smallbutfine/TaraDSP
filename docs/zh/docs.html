1. FFT 卷积

TaraDSP 使用 PFFFT（Pretty Fast FFT）库进行高速 卷积。处理过程如下：

  1. 输入信号和脉冲响应被零填充到下一个 2 的幂（PFFFT 对齐最少 32 个采样）。
  2. 两个信号通过正向 FFT （pffft_transform 配合 PFFFT_FORWARD）变换到频域。
  3. 频域信号通过 pffft_zconvolve_accumulate 相乘（卷积定理）。
  4. 结果通过逆 FFT （pffft_transform 配合 PFFFT_BACKWARD）变换回时域。
  5. 输出按 1/N 缩放并归一化到峰值 1.0。
为什么用 PFFFT？ PFFFT 专为音频 应用而设计。它支持实数 FFT（不只是复数）， 对于实数值音频信号快一倍。它还处理 SIMD 指令 （SSE、NEON）以获得额外速度。
重要： 必须使用 pffft_transform（内部格式）， 而不是 pffft_transform_ordered（显示格式）。 zconvolve_accumulate 函数期望内部格式。 使用错误的函数会产生不正确的卷积结果。

2. 重采样

TaraDSP 可以把音频重采样到不同的采样率。重采样 引擎选择遵循此优先级：

  1. SoX Resampler（libsoxr） — 最高质量，可用时使用
  2. R8Brain — 高质量，可用时使用
  3. FinalCD — 外部工具，可用时使用
  4. 线性插值 — 后备，始终可用

当请求重采样时（CLI 中的 -r 选项，或 GUI 中的采样率选择器），输入信号和脉冲 响应都会在卷积前重采样到目标采样率。

3. 母带抖动

输出 16 位音频时，TaraDSP 应用带误差反馈的 TPDF（三角概率 密度函数）抖动。此过程：

  1. 向信号添加少量随机噪声（2 LSB 峰峰值）。
  2. 量化为 16 位。
  3. 计算量化误差。
  4. 将误差反馈到下一个采样（误差反馈）。
为什么要抖动？ 没有抖动，量化为 16 位 会在低电平产生谐波失真。TPDF 抖动把 这种失真转换为恒定的低电平噪声底，这 更不被人注意，声音更自然。

4. 最小相位转换

线性相位脉冲响应具有对称的预 ringing，可能 听起来不自然。--min 选项（CLI）或「最小相位」 复选框（GUI）把卷积输出转换为最小相位，它具有：

  • 无预 ringing（能量只在主脉冲之后）
  • 更低延迟
  • 对箱体模拟和混响更自然的声音

转换算法：

  1. 计算信号的 FFT。
  2. 提取幅度谱。
  3. 计算对数幅度。
  4. 计算实数倒谱（对数幅度的逆 FFT）。
  5. 折叠倒谱以创建最小相位。
  6. 计算复数谱（幅度 × 最小相位）。
  7. 逆 FFT 得到最小相位信号。

5. 淡入淡出与修剪

TaraDSP 可以在卷积前对脉冲响应应用淡入淡出 并修剪静音：

  • 修剪（-t / GUI 微调）： 从 IR 的 开始和结束移除低于阈值（以 dB 计）的采样。用于 清理带静音填充的脉冲响应。
  • 淡出（-f / GUI 微调）： 对 IR 的 末尾应用指定时长（以 ms 计）的淡出。始终会应用 1ms 的淡入 以防止咔哒声。用于平滑 IR 的结尾。

6. 音频格式

输入

格式位深声道备注
WAV（PCM）8 位无符号任意内部转换为 float
WAV（PCM）16 位有符号任意最常见的格式
WAV（PCM）24 位有符号任意录音室标准
WAV（IEEE 浮点）32 位浮点任意完整动态范围

输出

位深格式抖动备注
16 位WAV（PCM）TPDF + 误差反馈CD 品质
24 位WAV（PCM）无录音室品质（推荐）
32 位WAV（IEEE 浮点）无用于进一步处理

7. 图形界面概览

图形界面在窗口中提供与 CLI 相同的 DSP 功能。 它由 gui/TaraDSP_gui.lpi 构建，使用 UIRCore.pas 提供共享的 DSP 函数。

控件说明
源文件输入 WAV 文件选择器
脉冲响应IR WAV 文件选择器（可选 — 为空则直通）
输出文件带浏览按钮的输出路径
位深16、24 或 32 位输出
采样率0（保持）、44100、48000、88200、96000、176400、192000
截断长度最大输出采样（0 = 无限制）
淡出应用于 IR 的淡出时长（ms）
修剪静音以 dB 计的阈值（负值启用修剪）
单声道输出下混为单声道
最小相位将输出转换为最小相位
PROCESS 按钮运行处理流水线
日志逐步进度输出

8. 从源代码构建

先决条件

  • FreePascal Compiler（FPC）3.2.2+ 或 Lazarus IDE 3.0+
  • 用于图形界面的 Lazarus/LCL
  • 完整多平台构建：FPC 交叉编译器 （ppcrossx64、ppcrossa64、ppcrossarm） 和 Inno Setup 6
  • Python 3（用于 tools/zip_app.py）
  • Zig（由 build_all.bat 自动下载，用于 Linux C 交叉编译）

构建全部

./build_all.bat            # 全部 5 个目标 + 打包到 Deploy/
./build_all.bat --check    # 仅验证工具链

构建单个程序

# CLI
fpc -O2 -Fusrc -Sg -Sc TaraDSP.lpr

# GUI
lazbuild --build-all gui/TaraDSP_gui.lpi
