平台产物备注
Windows 64 位 TaraDSP_<version>_Setup.exe Inno Setup 安装程序。包括图形界面、CLI、libpffft.dll 和配置。
macOS Intel TaraDSP_gui<version>-macos-intel.zip 通用应用包。解压并拖到 /Applications。
macOS Apple Silicon TaraDSP_gui<version>-macos-aarch64.zip 通用应用包。解压并拖到 /Applications。
Linux x86_64 TaraDSP<version>-linux-x64.tar.gz 解压并运行。包括 libpffft.so。
Linux ARM TaraDSP<version>-linux-arm.tar.gz 解压并运行。包括 libpffft.so。
macOS： 应用未进行代码签名。首次启动时， 请使用右键 → 打开（或在终端中 xattr -dr com.apple.quarantine）。
Linux： 压缩包包括 libpffft.so 共享库。确保它与 TaraDSP 可执行文件位于同一目录，或相应设置 LD_LIBRARY_PATH。

从源代码构建

构建说明见文档。简而言之：

./build_all.bat            # 全部 5 个目标 + 打包到 Deploy/
./build_all.bat --check    # 仅验证工具链
