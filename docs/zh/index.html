什么是 TaraDSP？

TaraDSP 是一款专业音频处理工具，采用基于 FFT 的卷积处理脉冲响应， 对音频进行重采样，并应用母带级别的抖动和淡入淡出。它专为需要从轻巧、跨平台命令行工具 中获得录音室级品质结果的音乐人、音频工程师和开发者而设计。

FFT 卷积

使用 PFFFT 库（Pretty Fast FFT）进行高速卷积。 在几秒钟内将任何音频信号与箱体脉冲响应、混响 IR 或自定义滤波器进行卷积。

跨平台

适用于 Windows（x86_64）、macOS（Intel + Apple Silicon） 和 Linux（x86_64 + ARM）的原生二进制文件。一个工具，覆盖所有平台。

母带抖动

TPDF（三角概率密度函数）抖动，带误差反馈，实现透明的 16 位和 24 位输出。

重采样

通过 SoX Resampler（libsoxr）进行高质量采样率转换， 并以线性插值作为后备。可在任意采样率之间转换。

最小相位

将线性相位脉冲响应转换为最小相位，实现 更低延迟和更自然的声音。

跨平台构建

使用 GitHub Actions 实现自动化 CI/CD。基于 fpcupdeluxe 的工具链会自动安装 FPC、Lazarus 和所有交叉编译器。

快速开始

将脉冲响应应用于音频文件：

TaraDSP -x input.wav -y impulse_response.wav -o output.wav

转换为 24 位并进行重采样：

TaraDSP -x input.wav -y ir.wav -o output.wav -b 24 -r 48000

应用淡入淡出并修剪静音：

TaraDSP -x input.wav -y ir.wav -o output.wav -f 50 -t -60
